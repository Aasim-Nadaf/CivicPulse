# CivicSolve

CivicSolve is a digital platform designed to help citizens report, track, and resolve local civic issues through a simple and transparent system.

## 🚀 Features

- Report civic issues
- Upload issue images and details
- Track complaint status
- View reported issues
- Transparent issue management
- User-friendly interface

## 🛠️ Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Shadcn UI
- Node.js
- Supabase

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/Aasim-Nadaf/civic-solve.git
cd civic-solve
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 🔐 Environment Variables

Create a `.env.local` file and add the required environment variables:

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```
